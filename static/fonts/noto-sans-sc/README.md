# Noto Sans SC (350)

Self-hosted WOFF2 subsets from Google Fonts, retrieved 2026-10-03:
https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@350&display=swap

Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
License: SIL Open Font License 1.1, retained in OFL.txt.

The original font files and unicode ranges are unchanged. Asset URLs in
350.css are relative; its CSS family alias is "Noto Sans SC Web" to avoid
colliding with installed fonts. Browsers download only subsets required
by the displayed characters. This is not a subset of the current biography:
normal text edits do not require regenerating the font.

Used only for mobile Academic prose at 350 weight. No third-party font
requests are needed at runtime; font-display: swap preserves readable
fallback text while fonts load or if a download fails.
